Al introducir un IBAN español en una cuenta bancaria, el **Código de entidad** aparece
debajo del BIC/SWIFT. El listado de cuentas bancarias lo tiene como columna opcional, y
su búsqueda permite filtrar y agrupar por él.

Las cuentas cuyo número no es un IBAN español válido no tienen código. Al instalar el
módulo se calcula el código de las cuentas existentes.
