Este módulo añade a las cuentas bancarias el código de entidad bancaria
española. Odoo 20.0 elimina los bancos (``res.bank``) y guarda los datos
bancarios en cada cuenta, así que el código se obtiene del número de
cuenta cuando es un IBAN español válido.

El código se almacena, de modo que se pueden buscar, filtrar y agrupar
las cuentas bancarias por él, y otros módulos lo pueden usar, como el
código de banco de las facturas Facturae.

Usage
=====

Al introducir un IBAN español en una cuenta bancaria, el **Código de
entidad** aparece debajo del BIC/SWIFT. El listado de cuentas bancarias
lo tiene como columna opcional, y su búsqueda permite filtrar y agrupar
por él.

Las cuentas cuyo número no es un IBAN español válido no tienen código.
Al instalar el módulo se calcula el código de las cuentas existentes.
