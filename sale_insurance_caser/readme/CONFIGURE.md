Go to *Settings > Sales > Caser Insurance* and configure:

1. **Caser Production Environment**: Enable for production, disable for test environment
2. **Caser Web Username**: Your Caser API username
3. **Caser Agency Code**: Your agency code (e.g., "9999")
4. **Caser Agent Code**: Your agent code (e.g., "9999999")
5. **Caser SICA Code**: Your SICA code (e.g., "9999")
6. **Caser Insurance Product Category**: Category of the insurance products
   created from the price ranges. Set an income account on it to book the
   insurance on that account instead of the default sales one. The category
   is applied to the existing products the next time their prices are
   updated from Caser.
