This module provides the Spanish localization (PGC) for the Professional
EBITDA report. It automatically maps the standard Spanish accounts to
the EBITDA KPIs, avoiding manual tagging for standard items.

Automatic mappings include:

- Corporate Taxes: 630\*
- Financial Expenses & Income: 66\*, 76\*
- Exceptional Items (Below EBITDA): 67\*, 69\*, 77\*, 79\*
- Financial Debt: 17\*, 52\*
- CAPEX (Fixed Asset Additions): 20\*, 21\*, 22\*

Installation
============

This module depends on account_ebitda_report and l10n_es.

Usage
=====

Just install this module alongside account_ebitda_report. When you
generate the EBITDA reports, the KPIs will automatically read the
balances from the standard Spanish PGC accounts.

For Custom M&A Normalizations and Working Capital, continue to use the
manual tags provided by the base module, as these vary by company.
