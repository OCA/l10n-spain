This module integrates Odoo's ``delivery`` framework (along with
``delivery_package_number``, ``delivery_state``, and
``stock_picking_volume``) with **Logista Parcel REST API v5**:

- **Expedition Registration
  (``POST /EnlaceB2B/app/integrations/shipment/v1``)**:

  - Supports Test (``qua-clientes.integra2.es``) and Production
    (``clientes.integra2.es``) environments with header token
    authentication.
  - Full support for all 9 Logista Parcel services (``AMBIPAQ``,
    ``URGEPAQ``, ``FRIOFARMA``, ``FRIOPAQ``, ``URGEFRIO``,
    ``FARMAPLUS``, ``AEREO FRIO``, ``FARMA < 25``, ``I2GOURMET``), Spain
    (``ES``), Portugal (``PT``), and Andorra (``AD`` -> ``AN``).
  - Automatic handling of unit parcels (``Packages``), pallets
    (``ControlPackages``), and mixed pallet + loose parcel shipments
    (``MixShipment``, ``MixPalets``, ``MixPackages``), volume (``m³``),
    insurance (``InsuranceValue``), cash on delivery
    (``CashOnDelivery``), SMS/Email notifications, arranged delivery
    dates, delivery note actions, tight flow, and ``ePackingList``.

- **Plaza & Delivery Zone Resolution (``wsRepartoProductoPorPlazas``)**:

  - Automatic destination delegation (``delegacion``) and delivery zone
    (``zonaReparto``) resolution for labels.

- **Official 34-Digit Code 128 Labels (PDF & Zebra ZPL)**:

  - Generates 100x150mm **PDF** (QWeb) and **ZPL** thermal labels for
    both parcels (``Bto.``) and pallets (``Pal.``), including the
    34-character Code 128C/B barcode per Logista Parcel Labelling
    Specification v4.

Installation
============

It depends on ``delivery_package_number``, ``delivery_state``, and
``stock_picking_volume`` from ``OCA/delivery-carrier`` and
``OCA/stock-logistics-workflow``.

Configuration
=============

To configure this module:

1. Go to **Inventory > Configuration > Delivery > Shipping Methods** (or
   **Sales > Configuration > Shipping Methods**).
2. Open the preconfigured **Logista Parcel** shipping method (or create
   a new one with **Provider** = ``Logista Parcel``).
3. In the **Logista Configuration** tab:

   - Enter your **Logista API Token** and **Sender Code
     (``Sender.Code``)** provided by Logista Parcel, and toggle
     **Production Environment** when ready.
   - Select your **Logista Parcel Service** (e.g. ``1 - AMBIPAQ``,
     ``4 - FRIOPAQ``), **Sector Code** (``0`` Generic, ``1`` Pharma,
     ``2`` Food, etc.), and **Default Freight Type** (``P`` Prepaid /
     ``D`` Collect).
   - Set your 2-digit **Origin Delegation Code** and 6-digit **Barcode
     Customer Code** for the 34-digit Code 128 label barcode, and choose
     your preferred **Label Format** (``PDF`` or ``ZPL``).
   - *(Optional)* Configure a **Default Fixed Price** or **Price Rules**
     by weight/volume/packages.

Usage
=====

Sending Shipments & Printing Labels
-----------------------------------

1. Validate the outgoing **Delivery Order** (``stock.picking``) or click
   **Send to Shipper**.
2. Odoo registers the expedition in Logista Parcel
   (``POST /shipment/v1``), queries ``wsRepartoProductoPorPlazas`` for
   the destination delegation and delivery zone, assigns 34-digit
   barcodes to physical packages (``stock.quant.package``), updates
   ``delivery_state`` and ``carrier_tracking_ref`` (``ShipmentId``), and
   attaches the **PDF or ZPL label** in the chatter.
3. Click **Logista Label** on the picking form at any time to reprint
   the shipping label, or **Print Return Label** on return pickings.
