Este módulo complementa a ``l10n_es_deca`` para permitir la impresión
del documento de control administrativo electrónico (DeCA) desde las
**Agrupaciones de Albaranes** (Batch Pickings).

Separa la dependencia directa de ``stock_picking_batch`` del módulo
principal para mantener la modularidad y no forzar su instalación a
quienes no usan agrupaciones.

Más información en la página oficial: `Documento Electrónico de Control
Administrativo
(DeCA) <https://www.transportes.gob.es/transporte-terrestre/profesionales-transporte/servicios-transportista/documento-electronico-control-administrativo-deca>`__.

Configuration
=============

No se requiere configuración adicional tras la instalación. Se necesita
tener instalado el módulo ``stock_picking_batch``.

Usage
=====

1. Vaya a la agrupación de albaranes (Inventario > Operaciones >
   Agrupaciones de albaranes).
2. Seleccione un lote que contenga operaciones de salida.
3. En el menú "Imprimir", seleccione "DeCA".
