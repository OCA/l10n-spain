Este módulo complementa a `l10n_es_deca` para permitir la impresión del
documento de control administrativo electrónico (DeCA) desde las
**Agrupaciones de Albaranes** (Batch Pickings).

Separa la dependencia directa de `stock_picking_batch` del módulo
principal para mantener la modularidad y no forzar su instalación a
quienes no usan agrupaciones.

Más información en la página oficial: [Documento Electrónico de Control
Administrativo
(DeCA)](https://www.transportes.gob.es/transporte-terrestre/profesionales-transporte/servicios-transportista/documento-electronico-control-administrativo-deca).
