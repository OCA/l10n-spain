Este módulo permite configurar el valor predeterminado del campo "Usar informes del 303" 
para nuevos informes del modelo 390.

Para configurarlo, **Contabilidad > Configuración > Ajustes > Modelo 390** 
y marcar o desmarcar **Usar informes del 303 en Modelo 390**.

Cuando está activado, los nuevos informes 390 se crearán con este campo
seleccionado por defecto.
