Account invoices already issued by another SIF without issuing them again from Odoo.

External invoices remain available for accounting, taxes, payments, and reconciliation,
but they do not enter the VERI*FACTU flow and cannot be printed or sent from Odoo.

**Table of contents**

.. contents::
   :local:

Installation
============

Install this module only when invoices issued by another SIF must be accounted for.

Usage
=====

Create an external SIF sales journal, or classify an existing journal that has not
generated VERI*FACTU entries yet. Use that journal exclusively for invoices already
issued by the other SIF.
