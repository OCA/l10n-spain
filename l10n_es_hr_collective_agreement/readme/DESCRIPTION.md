Este módulo depende de `hr_collective_agreement` y proporciona datos iniciales
de configuración para convenios colectivos en España.

Incluye valores predefinidos para:
- Publicaciones oficiales (p. ej. BOE, DOGC)
- Ámbitos (Autonómico, Provincial, Comarcal, etc.)

Estos registros facilitan la configuración inicial de los convenios colectivos.
