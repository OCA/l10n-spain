Glue module to send Canary Islands IGIC invoices through AEAT
VERI*FACTU.

It maps native ``es_canary_*`` taxes and fiscal positions (clave
impuesto ``03``) onto ``l10n_es_verifactu_oca``. The SOAP endpoint is
AEAT, not ATC.

Before installing, set the Canary tax agency on the company so draft
invoices and fiscal positions get tax key ``03``.

Installation
============

Install ``l10n_es_verifactu_oca`` first. Configure the company with the
Canary tax agency, a test AEAT certificate, developer and chaining
records, then install this module.

Use ``account_chart_update`` if fiscal positions already exist so they
pick up the IGIC VERI*FACTU keys.

Configuration
=============

Set the company tax agency to Canarias. Enable VERI*FACTU on the company
in test mode until you are ready to send to AEAT.

Fiscal positions of the Canary chart get tax key ``03`` and the matching
IGIC registration keys (export ``02``, retailer ``17``, etc.).

Usage
=====

When an invoice is posted, the VERI*FACTU queue is created as in
``l10n_es_verifactu_oca``. IGIC invoices use tax key ``03``.

Retailer regime (key ``17``): use the retailer fiscal position and the
theoretical IGIC rate on the product (``igic_r_*``). The module computes
the implicit tax load as in art. 29.3 of Ley 20/1991:
``Carga = Base × (0,7 × T) / 100``.

On install or upgrade, draft customer invoices of Canary companies
receive IGIC keys. Posted invoices are left unchanged.
