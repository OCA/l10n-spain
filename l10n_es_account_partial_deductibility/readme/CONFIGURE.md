No necesita configuración: en las compañías españolas, la parte privada se queda siempre
en la cuenta de cada línea, aunque el diario de compras tenga una "Cuenta de acciones
privadas" (el plan contable español de Odoo core pone la 544).

Si una compañía quiere el comportamiento de Odoo core, con la parte privada en la cuenta
de acciones privadas del diario (por ejemplo, la cuenta del titular de un autónomo que
se imputa a sí mismo el uso privado), no debe instalar este módulo.
