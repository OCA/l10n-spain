Este módulo incorpora la casilla 522 al informe del modelo 390, la cual
se utiliza en aquellos casos en que la empresa está sujeta al régimen de
prorrata del IVA.

Cuando se obtenga la prorrata definitiva del año se debería de aplicar a
todos los apuntes, pero estos no se pueden modificar ya que están
contabilizados. Para estos casos, el modelo 390 incluye la casilla 522,
destinada a reflejar la regularización de las deducciones provisionales
derivadas de la aplicación del porcentaje definitivo de prorrata.

Use Cases / Context
===================

Este módulo se ha desarrollado con el objetivo de incorporar la casilla
522 al informe del modelo 390.

Usage
=====

Para crear un modelo 390:

1. Realizar la declaración 390 de la forma habitual.
2. El IVA deducible ya vendrá minorado por el porcentaje de la prorrata.
3. Ir a **9. Resultado liquidaciones** y la casilla 522 se mostrará el
   importe de la prorrata que se minoró.
