1. Open an outgoing transfer, or an incoming transfer whose operation type has **Enable DeCA** enabled, from **Inventory > Operations > Transfers**.
2. In the **DeCA** tab, enter the required **Main vehicle or tractor licence plate** and **Carrier contact** (with VAT/NIF). The trailer plate and special traffic authorizations are optional.
3. Check the required sender, consignee, carrier, and weight data. For outgoing transfers, the sender is the warehouse contact (or company) and the consignee is the transfer contact; incoming transfers invert this direction.
4. Click **Print DeCA** to generate the PDF. Missing required data is reported by name.
5. Click **Share DeCA** and confirm the warning to open a link to the current PDF. A QR code for that link is included in the report.
6. If printed data changes, print or open the share link again to create a new version. Earlier versions remain attached to the transfer while it exists; the current version is shown by **DeCA Version**.

The PDF is generated when printed or when a valid share link is opened; it is not emitted as a separate workflow step or frozen automatically when the transfer is completed. If printed data is unchanged, the current PDF is reused. After completion, changes to the main vehicle plate, trailer plate, and special authorizations retain the previous values, which are shown struck through in later versions.
